# WorkBoard

> WorkBoard (WorkBoardAI) is an AI-native strategy, OKR, and strategic portfolio management platform for enterprises. Its REST APIs expose users, teams, goals (objectives), metrics (key results), action items, workstreams, and datastreams; a SCIM 2.0 API handles user provisioning; and a published MCP server gives AI agents scoped access to OKRs, KPIs, scorecards, business reviews, and meetings.

Generated by API Evangelist from the WorkBoard developer surface (no /llms.txt is published by the provider; probed 2026-07-21).

## APIs

- [WorkBoard External API v1](https://apidocs.myworkboard.com/): REST API for user, goal, and metric data. Production root: https://www.myworkboard.com/wb/apis
- [WorkBoard Public API v2](https://apidocs.myworkboard.com/): Custom attributes API (objectives, key results, work items, users). Production root: https://www.myworkboard.com/wb/apis/v2
- [WorkBoard SCIM API](https://support.myworkboard.com/en/articles/13516753-workboard-system-for-cross-domain-identity-management-scim-api-reference): SCIM 2.0 user provisioning. Root: https://myworkboard.com/wb/apis/scim

## Specs

- [OpenAPI v1 (External)](https://apidocs.myworkboard.com/openapi.json): OpenAPI 3.0.1, 47 operations across User, Team, Goal, Metric, Activity, Workstream, Datastream, Tags, Webhook
